ESTRUCTURA DEL PROYECTO
=========================

index.html
- Página principal.
- Contiene la estructura y contenido HTML.

css/
- estilos.css: estilos que originalmente estaban dentro del HTML.

js/
- juego.js: código JavaScript que originalmente estaba dentro del HTML.

img/
- Recursos gráficos extraídos del HTML/CSS cuando estaban incrustados.
- No se encontraron imágenes Base64 para separar.

La estructura está organizada para que el proyecto pueda presentarse como un proyecto web:
HTML → estructura
CSS → diseño
JavaScript → interactividad
IMG → recursos gráficos

Abre index.html en un navegador para ejecutar el proyecto.
