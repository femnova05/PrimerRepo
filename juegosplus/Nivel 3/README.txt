ESTRUCTURA DEL PROYECTO — FEMNOVA NIVEL 3

index.html
- Contiene la estructura y el contenido de la página.
- Conserva los SVG inline porque forman parte de las ilustraciones del HTML.
- Carga la hoja de estilos externa y el JavaScript externo.

css/estilos.css
- Contiene todos los estilos que estaban dentro de <style>.
- Incluye variables de color, diseño, responsive y estados visuales.

js/app.js
- Contiene todo el JavaScript que estaba dentro de <script>.
- Incluye la lógica de las actividades, conversaciones, puntuación, botones, aguja y resultados.

Dependencia externa:
- Las fuentes se cargan desde Google Fonts mediante el enlace que permanece en index.html.
